# GrouSave Mobile App (Expo / React Native)

### Run the App
```bash
npm install
npx expo start
```
Scan the QR code with **Expo Go** on Android or iOS.

### Features
- **11 Pixel-Perfect Screens** strictly matching the UI reference image.
- **Floating Screen Switcher** (top right pill button) to jump directly to any of the 11 screens.
- **Natural In-App Navigation Flow**:
  - Welcome -> Home -> Service Listing -> Service Details (Single / Group) -> Cart -> Payment -> Booking Confirmed -> Booking Details -> My Bookings.
- **Global Cart & Bookings State**: Items can be incremented, decremented, removed, and booked.
